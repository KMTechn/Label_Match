## 2. 처리 중 입력 규칙

> **아래 처리 중 표시는 멈춤이 아닙니다.** 표시가 사라지고 다음 행동 안내가
> 바뀔 때까지 같은 PHS2나 제품을 다시 스캔하거나 F3/F4를 반복하지 마세요.

현재 소스의 표준 PHS2/F4/F3 경로는 다음 문구를 그대로 표시합니다.

| 작업 | 화면의 처리 중 문구 |
| --- | --- |
| PHS2 접수·검증 | `현품표 저장 · 중앙 확인 중` |
| F4 준비 | `제품 교체 · 중앙 확인 중` |
| F4 포장 상태 확인 | `제품 교체 · 포장 상태 확인 중` |
| F4 중앙 처리 | `제품 교체 · 중앙 처리 중` |
| F3 사전 확인 | `포장 완료 · 현재 제품 집합 확인 중` |
| F3 완료 권한 확인·로컬 저장 | `포장 완료 · 권한 확인 및 로컬 완료 저장 중` |

처리 중 상태줄에는 위 문구 뒤에
`처리 완료 전 추가 입력은 받지 않습니다.`가 붙습니다.

처리 중에 추가 입력을 시도하면 화면은
`이전 작업 처리 중 · 입력 보존`과
`처리가 끝나지 않아 이번 입력은 접수하지 않았습니다. 입력을 보존했습니다.`를
표시합니다. 이 경우 입력칸의 값은 지워지지 않습니다. 같은 바코드를 다시 찍지
말고, 처리 중 표시가 끝난 뒤 입력칸에 보존된 값을 확인하여 한 번만 제출하세요.

`PENDING` 또는 timeout이 확인된 경우에도 같은 PHS2·F3를 반복하지 말고 자동
재시도를 기다리세요. 이 문구는 기존 작업자 안내의 반복 금지 원칙을 그대로
유지합니다.

## 3. 완료·대기·충돌 안내

- F3는 **로컬 완료 저장 → 중앙 전송 대기 → 중앙 확정** 순서입니다. 완료 권한을 확인하고 로컬 기록을 안전하게 저장하는 중에는 아직 완료가 아닙니다.
- `로컬 완료 저장됨 · 중앙 전송 대기`는 로컬 완료가 보존되어 자동 전송하는 상태입니다. 중앙 확정과 구분하며 다음 포장 준비는 가능합니다. `중앙 확정`은 중앙이 같은 작업의 완료를 확인한 상태입니다. 대기 현황에서 후속 전송·결과 확인·관리자 경고를 계속 확인하세요.
- `로컬 포장 완료 복구 중`이 보이면
  `저장된 포장 완료 기록을 복구하고 있습니다. 복구가 끝날 때까지 PHS2를 이동하거나 다음 포장을 시작하지 마세요.`를 따르세요.
- `중앙 포장 충돌 · 실물 작업 중지`가 보이면 실물을 구분 보관하고 화면 안내에
  따라 작업 리더 또는 관리자에게 중앙 상태 확인을 요청하세요. 저장된 로컬 완료
  기록을 삭제하지 마세요.
- `처리 상태 확인 필요`와
  `처리 상태를 확인할 수 없습니다. 추가 스캔을 중지하고 관리자에게 문의하세요.`가
  보이면 추가 스캔을 중지하세요.
- 처리 중 종료를 요청해 `처리 완료 후 종료합니다`가 보이면 작업이 끝날 때까지
  창을 강제로 종료하지 마세요.

## 4. 반복 금지와 실물 보존

- 이미 로컬 완료가 기록된 작업을 새 PHS2나 새 F3 입력으로 다시 만들지 마세요.
- `PENDING`/timeout은 완료 여부가 불명확한 새 작업을 만들라는 뜻이 아닙니다.
- 충돌·관리자 확인 상태에서는 DB, CSV, 현재 상태 파일과 outbox를 직접 수정하거나
  삭제하지 마세요.
- 입력이 접수되지 않았다는 안내와 입력칸에 보존된 바코드는 구분하세요. 현재
  Label_Match는 busy 거절 때 입력칸 값을 보존하므로 재스캔하지 않습니다.
